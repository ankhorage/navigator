# @ankhorage/zora-navigation

Responsive, theme-aware navigation components for ZORA on React Native and React Native Web.

> The package API is not implemented or published yet. The repository is prepared for a focused owner-first implementation.

## Intended ownership

`@ankhorage/zora-navigation` will own reusable ZORA-styled Tabs, Drawer, responsive navigation presentation, and their supported Expo Router integration.

Application-specific routes, authentication state, authorization policy, and Studio generation remain with their respective owners.

## Development

bun install --frozen-lockfile
bun run build
bun run lint
bun run test
bun run knip
